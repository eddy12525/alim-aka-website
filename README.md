# Alim's Truck Repair — Website

Mobile semi truck & trailer repair website. Plain static site (HTML/CSS/JS), no build step.

- `index.html` — all page content
- `styles.css` — styling (dark + safety orange theme)
- `script.js` — "Use my location" button on the request form
- `assets/logo.svg` — logo / favicon

## Preview
Open `index.html` in a browser.

## Request form
The form sends to turanov1986alim@gmail.com via [FormSubmit](https://formsubmit.co).
The **first** submission triggers a one-time confirmation email to that inbox — click the link in it to activate the form.

## Hosting (free)
GitHub Pages: repo Settings → Pages → Deploy from branch → select this branch, `/ (root)`.
Or drag the folder onto https://app.netlify.com/drop.
