# Alim's Truck Repair — Website

Mobile semi truck & trailer repair website. Plain static site (HTML/CSS/JS), no build step.

- `index.html` — all page content
- `styles.css` — styling (dark + safety orange theme)
- `script.js` — footer year
- `assets/logo.svg` — logo / favicon

## Preview
Open `index.html` in a browser.

## Placeholders to replace before promoting the site
- **Reviews** (`#reviews` in `index.html`) are sample text. Swap in real customer reviews (e.g. from Google).
- **Photos** are AI-generated and currently loaded from Higgsfield's CDN. Replace with real photos of Alim's truck and jobs,
  saved in `assets/img/` (compressed JPG/WebP, ~200–400 KB each) so the page loads fast on phones.
