# Business cards

- `alims-business-cards-print.pdf` — print-ready, 2 pages (page 1 = front, page 2 = back)
  - Size 3.75" × 2.25" = standard 3.5" × 2" card + 0.125" bleed on every side
  - Text kept 0.125" inside the trim line
- `card-front.png`, `card-back.png` — 600 dpi previews (also usable for upload)

Upload the PDF to Vistaprint, Moo, GotPrint, Staples, etc. and choose "I have a design with bleed".
The QR code on the back opens https://eddy12525.github.io/alim-aka-website/ — reprint if the website address changes.
